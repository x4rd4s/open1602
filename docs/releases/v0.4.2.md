## What's new in 0.4.2

Changes since [0.4.1](https://github.com/x4rd4s/open1602/releases/tag/v0.4.1).

Multiplayer games need every player on 0.4.2: the setting below changes how fields bear, so 0.4.1
cannot join a 0.4.2 game.

### Changed

- **Barren patches instead of fertile fields:** the "Fertile fields" setting in the "Nature" group
  is now called "Barren patches" and does less. As in the original, the ground under a tile still
  weighs the island's fertility for a crop, so single tiles stay barren even where the island grows
  the crop fully. Set to "Fertile", poor ground no longer takes anything from a field: every tile
  has the island's fertility. A crop the island grows only partly still bears on as many tiles as
  before, a crop it does not grow still does not, and droughts still wither. Off by default; games
  saved with the old setting keep it on and play with the new rule.
